# Схема данных MVP

Миграции находятся в `src/auth/infrastructure/persistence_sqla/alembic/versions`.

```text
users 1 -- * orders 1 -- * order_items
```

- `orders`: идентификатор, пользователь, статус, даты и причина отмены;
- `order_items`: позиция заказа, название, количество и цена на момент заказа.

В минимальном объёме меню задано статически в API: отдельные таблицы заведений и меню не нужны для сценария «посмотреть меню → оформить заказ».
